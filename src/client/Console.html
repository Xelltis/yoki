合言葉

この画面を開く全員で使う合言葉です。一度入れたブラウザは、ログアウトするか合言葉が変わるまで二度と求めません。メンバーを外したときはここで変えると、その人は次に開いたときから見られなくなります。

忘れたときは、シートのメニュー「卓予定 → ウェブアプリの合言葉を設定…」から決め直せます。

Webhook URL の取り方

  1. Discord で、知らせを流したいチャンネルの チャンネルの編集（歯車）を開く。スマホはチャンネルを長押しして「チャンネルを編集」。
  2. 連携サービス → ウェブフック を開き、新しいウェブフック を押す。
  3. できたウェブフックを押して開く。名前とアイコンは好みで変えてよい。投稿先のチャンネルが合っているか確かめる。
  4. ウェブフック URL をコピー を押す。
  5. この画面の URL の欄に貼って保存し、「接続テスト」で届くか確かめる。

「連携サービス」が出てこないときは、そのサーバーで「ウェブフックの管理」の権限がありません。サーバーの管理者に作ってもらうか、権限をもらってください。

URL を知っている人は、誰でもそのチャンネルに投稿できます。卓の仲間の外には出さないでください。
