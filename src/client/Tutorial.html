卓予定の使い方

卓予定は、仲間の都合から全員が空いている日を見つけて、卓の日程を決めるまでを 1 か所で済ませるウェブアプリです。GM は上の 3 ステップで準備し、あとは章ごとに読めます。例の画面は押して試せます。

3 ステップで始める

使い始めるときに、GM が次の順で準備します。合言葉は、最初に開いたときに画面が聞いてくるので、ここでは省きます。

  1. STEP 1

    メンバーを登録する

    person_addメンバーの登録 タブで、卓に出る人の名前を入れます。ここで入れた名前が、予定表の列と参加者の候補になります。Discord のユーザー ID も入れておくと、通知でその人にメンションが付きます。

  2. STEP 2

    Discord を登録する

    settings設定 タブの「Discord」に Webhook URL を貼って「URL を保存」を押し、「接続テスト」で届くか確かめます。Webhook の取り方は、URL を貼る欄の横にある「？」を押すと出ます。開催前の知らせを自動で送るなら「開催前の知らせ」も有効にします。Discord を使わないなら飛ばせます。

  3. STEP 3

    予定を登録する

    calendar_monthカレンダー で日を選んで add卓を登録 を押します。日が決まっていなければ、状態を「募集」か「調整中」にして登録します。

みんなメンバーの予定

予定を入れる

付けるのは行けない日の印だけです。全員の印から、全員が空いている日がカレンダーに浮かびます。

  • person
    右上の「あなた」で自分を選ぶ

    予定を書く列と、参加希望や回答の名前がここで決まります。選んだ名前はブラウザが覚えます。名前が無ければ GM にメンバーの登録を頼みます。

  • touch_app
    押すたびに印が変わる

    空欄 → △ 調整すれば行ける → × 行けない → 空欄 の順に回ります。押した瞬間にシートへ書かれます。

  • edit
    鉛筆でその日のメモ

    マスの右上の鉛筆から「21 時から」「午前だけ」のような一言を書けます。水色の点が付き、ほかの人にも見えます。

  • date_range
    同じ印はまとめて入れる

    まとめて入れる で期間と曜日を選ぶと、「平日はずっと ×」のような入れ方が一度で済みます。

  • group
    「参」「GM」は自動で付く

    その日の卓に入っている人のマスには、自動で付きます。自分では変えられません。

みんなカレンダー

カレンダーを読む

マスの色は、みんなの都合です。卓の札とアイコンで、その日に何があるかが分かります。

  • filter_alt
    「都合を見る卓」で相手を絞る

    卓を選ぶと、その卓の GM と参加者の都合だけで色が付きます。「全員」ならメンバー全員です。

  • touch_app
    日を押すと内訳が出る

    その日の卓の時間・GM・参加者・場所と、メンバーの予定が並びます。スマホではカレンダーのすぐ下に出ます。

  • swipe
    スマホは左右になぞって月送り

    左になぞると次の月、右になぞると前の月です。

みんな募集・調整

卓に参加する

募集中の卓には「参加希望」か「興味あり」を付けます。押しても Discord には流れないので、気軽に付けて大丈夫です。

  • how_to_reg
    参加希望は、そのまま参加者になる

    GM が卓の状態を「調整中」か「開催」にすると、参加希望の人は参加者に入ります。

  • star
    興味ありは、声をかけてほしい印

    GM が「興味ありの人に聞く」を送ると、Discord でメンションが届きます。行けそうなら参加希望に切り替えれば、それが返事になります。GM が開催に移すとき、興味ありのままの人は参加者にするか外すかを GM が選びます。

  • undo
    いつでも取り消せる

    もう一度押し直せば切り替わり、「取り消す」で外れます。

みんな募集・調整

日程調整に答える

GM が候補日を出すと、Discord に知らせが届きます。候補日ごとに ◯ か × を押します。全員が答えると GM に知らせが届き、GM が開催日を選びます。

  • how_to_vote
    「募集・調整」タブで答える

    日程調整中のカードに候補日が並びます。同じ印をもう一度押すと取り消せます。

  • check
    どの日でもよければ 1 回で済む

    候補日の見出しの右にある どの日でもいい を押すと、これからの候補日すべてに ◯ が付きます。もう一度押すと、自分の回答だけを取り消せます。

  • event_available
    開催日は GM が選ぶ

    全員の回答がそろうと、GM に Discord で知らせが届きます。GM が候補日の「この日に決める」を押すと状態は「開催」になり、Discord に「日程が決まりました」と流れます。

  • notifications_active
    自分の番は「卓予定」に出る

    カレンダーの右（スマホでは下）に「あなたの回答を待っています」と色付きで出ます。

みんな画面の右上

最新の状態にする

ほかの人が書いた内容は、自動更新で数分おきに画面へ入ります。すぐ見たいときは「更新」を押します。

  • refresh
    「更新」で今すぐ読む

    アイコンが回り、終わると「最新の状態にしました」か「変更はありません」と吹き出しに出ます。

  • sync
    自動更新は 3 分ごと

    変わったときだけ描き直し、「ほかの人の変更を反映しました」と出ます。間隔は settings設定 タブの「この端末」で変えられます。

  • edit_note
    書きかけは消えない

    文字を入力中や窓を開いているあいだは、読み込みを待ちます。

GMカレンダー

卓を登録する

カレンダーで日を選んでから add卓を登録 を押すと、その日の卓として登録の窓が開きます。

  • today
    日を選ぶと、ボタンの名前も変わる

    「10/9 に卓を登録」のように、どの日の卓になるかがボタンに出ます。選ばずに押すと、開催日は空のまま開きます。

  • checklist
    状態を選ぶと、手順が出る

    登録の窓で状態を選ぶと、その下に「開催」「募集」「調整中」それぞれの進め方が 3 段で出ます。いまどの段かも分かります。

  • event_busy
    日が決まっていない卓

    状態を「募集」にすると「開きたい期間」、「調整中」にすると「候補の期間」を入れて登録できます。どちらも 10/3〜10/17 のような日の幅です。「卓を登録」の隣の「募集を始める」「日程調整を始める」を押すと、状態が入った窓がすぐ開きます。開催日を入れて保存すると「開催」になります。

  • library_add
    何日かに分けて開く卓はシリーズで束ねる

    1 日で終わる卓には要りません。シリーズ名を選ぶと、直前の回の GM・参加者・時間・場所・メモを引き継ぎます。「日を足す」で何日分もまとめて登録できます。単発の卓でも「続きを登録」を押すと、前の回と合わせてシリーズになります。シリーズの最終日を入れておくと、その日を過ぎた分は候補から消えます。

  1. campaign募集

    参加者を集める。日の代わりに「10/3〜10/17」のような開きたい期間を持つ。参加者はまだ書かない

  2. edit_calendar調整中

    参加者は決まり、候補の期間や候補日から開催日を選ぶ

  3. event開催

    開催日が決まった。決めた日時（既定は前日の 20 時台）に Discord へ通知が届く

  4. task_alt終了

    開催日を過ぎると自動で変わる。カレンダーには灰色で残る

block開かないと決まった卓は「中止」にします。どの状態からでも選べ、カレンダーには取り消し線付きで残ります。

GM募集・調整

日程を決める

調整中の卓のカードで how_to_vote日程を調整する を押し、候補日を選びます。卓を「調整中」で登録したときは、保存するとこの窓がそのまま開きます。

  • checklist
    候補日の横に、みんなの予定が出る

    各日の右に GM と参加者の印（全員空き・△・×・卓あり）が並びます。「全員空きの日だけ」で絞り込めます。

  • send
    「この候補日で聞く」で知らせる

    「Discord で知らせる」を付けたまま送ると、GM と参加者を呼んで、候補日と答え方を流します。出した人の ◯ は最初から付いています。

  • tune
    選び直す・やめる

    「候補日を選び直す」では、外した日の回答だけが消えます。「調整をやめる」で候補日と回答を消しても、卓は調整中のまま残ります。

GMDiscord

Discord に知らせる

通知は Discord のチャンネルに届きます。メンバーの登録で Discord のユーザー ID を入れておくと、その人にメンションが付きます。

  • schedule
    開催前の知らせ

    settings設定 タブで「開催日の何日前の何時台」を決めて有効にすると、その日時に卓の知らせが届きます。0 日前なら当日、1 日前なら前日です。

  • tune
    開催前の知らせと募集を別のチャンネルに分ける

    設定タブの「種類ごとのチャンネル」に URL を貼ると、開催前の知らせと募集の知らせ（募集の卓の登録や、興味ありの人への参加確認）だけを、そのチャンネルに送れます。空なら基本のチャンネルへ届きます。

  • alt_route
    シリーズごとにチャンネルと日時を変える

    設定タブの「シリーズごとの通知」で、シリーズ専用の Webhook URL と開催前の知らせの日時を決められます。「基本のチャンネルにも送る」を付けると、両方に届きます。決めていないシリーズは、基本のチャンネルへ基本の日時に届きます。

  • hourglass_top
    期間の前日に催促が届く

    募集中・調整中のまま期間の始まる前日になると、GM にメンション付きで届きます。開催前の知らせと同じ時刻台です。設定タブの「そのほかの知らせ」で止められます。

  • alarm
    開始の少し前に知らせる

    設定タブの「そのほかの知らせ」で ON にすると、卓の当日、開始の◯分前に GM と参加者へ届きます。開始時刻を入れた「開催」の卓だけです。5 分ごとの見回りで送るので、少し遅れて届きます。

  • campaign
    卓の案内をいま送る

    カレンダーで日を押し、内訳の「Discord に通知」を押します。登録や変更の窓の「Discord に知らせる」を付けても流れます。

  • forum
    興味ありの人に聞く

    募集中の卓で、興味ありの人にメンションして参加できそうかを尋ねます。一言を添えられます。

  • shield
    管理者だけができること

    設定タブの「管理者」で管理者の合言葉を決めると、シートを開く・ほかの人のぶんを入れる・メンバーと設定を変える・卓を消す、が管理者だけになります。最初の合言葉を決めた人が最初の管理者で、あとから何人でも増やせます。

  • receipt_long
    届かないときは送信記録

    設定タブの「最近の送信記録」に、届かなかった理由が出ます。ツールの不具合でなければ、そう書かれます。

困ったときよくある質問

よくある質問

「あなた」に自分の名前がないexpand_more

「メンバーの登録」タブで名前を足します。卓の参加者に書かれている名前と同じ表記にしてください。足すと「あなた」の候補と、予定表の列に出ます。

合言葉を忘れたexpand_more

シートを管理している人に聞いてください。管理している人は、シートのメニュー「卓予定 → ウェブアプリの合言葉を設定…」から決め直せます。決め直すと、全員が新しい合言葉を入れ直します。

共用の PC で開いてしまったexpand_more

ログアウトすると、そのブラウザが覚えた合言葉が消えます。PC では右上のボタン、スマホでは設定タブの「この端末」にあります。

ほかの人が入れた予定が出てこないexpand_more

右上の「更新」を押してください。時刻の横の点が赤いときは読み込めていないので、通信を確かめてから押し直します。

決まった日を変えたいexpand_more

カレンダーでその日を押し、内訳の「編集」から開催日を直します。窓の「Discord に知らせる」を付けて保存すると、変更がみんなに流れます。

はじめの 3 ステップをもう一度見たいexpand_more

上の「使い方」の隣にある「はじめの 3 ステップ」を押すと、カレンダーの上にもう一度出ます。スマホでは、上の帯にある旗のボタンです。もう一度押すか、右上の × を押すと閉じます。

押しても何も起きないexpand_more

「上の『あなた』で自分を選んでください」と出ていれば、右上の「あなた」で自分を選びます。窓が開いたままのときは、Esc か「閉じる」で閉じてから押します。
