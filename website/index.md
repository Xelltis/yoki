# 特長（theme/components/HomeFeatures.vueが出す。iconはtheme/icons.tsの名前）
points:
  - icon: event_available
    title: 全員が空いている日が分かる
    details: 付けるのは、行けない日の印（△・×）だけです。全員の印から、全員が空いている日がカレンダーに浮かびます。
  - icon: how_to_vote
    title: 募集も日程調整も
    details: 参加者を募り、候補日に ◯ か × で答えてもらい、GMが開催日を決める。ここまでを1か所で進められます。
  - icon: auto_stories
    title: シナリオの通過が分かる
    details: だれがどのシナリオを通過したかをまとめます。未通過で空いている人がそろう日が分かり、その日の卓をすぐ立てられます。
  - icon: checklist
    title: HOとキャラシを配って集める
    details: HOの希望と割り当て、本人だけが読める秘匿HO、キャラシの提出と締め切りの催促まで、卓の前の準備を1つの窓で進めます。
  - icon: notifications
    title: Discordに自動で知らせる
    details: 開催前の知らせ、日程調整の呼びかけ、回答がそろったことを、チャンネルに送ります。メンションも付きます。
  - icon: event
    title: Discordのイベントに出す
    details: 開催の決まった卓を、Discordのサーバーのイベントにも出せます。卓を変えたり中止にしたりすると、イベントも直ります。
  - icon: login
    title: Discordでログイン
    details: グループはDiscordサーバーごとに作ります。入れるのは、そのサーバーにいる人だけです。Googleのアカウントを結びつければ、Googleでもログインできます。
  - icon: calendar_month
    title: いつものカレンダーに出す
    details: 参加する卓を、ふだん使っているカレンダーに出せます。購読URLか、Googleカレンダーとの連携を選べます。
  - icon: rocket_launch
    title: 自分で設置できる
    details: MIT LicenseのOSSです。「Deploy to Cloudflare」のボタンから自分のCloudflareに設置でき、無料のプランで動きます。新しい版にも、管理画面から追いつけます。
