# メンバーと管理者

## グループに入れる人

- グループに入れるのは、そのグループの Discord サーバーにいる人だけです。URL を知っていても、サーバーにいなければ入れません
- ログインは 30 日で切れます。入っているサーバーは 1 日に 1 回、Discord に聞き直します（画面はほとんど出ません）。サーバーを抜けた人は、1 日ほどで入れなくなります

## メンバー

- 初めてグループを開いた人は、Discord の表示名で自動でメンバーになります。Discord の ID も自動で入るので、知らせでその人にメンションが付きます
- 同じ名前のメンバーがすでにいれば、「名前 (2)」のように番号が付きます。名前は、本人なら右上の自分の名前から開く <Ui icon="settings">設定</Ui> の「あなたの名前と備考」で、管理者なら[管理画面](./admin)の「メンバー」で直せます
- まだ開いていない人は、管理者が管理画面の「メンバー」で先に足せます。Discord の ID を入れておけば、その人が初めて開いたときに、その行に結びつきます
- 卓の参加者には、メンバーに無い人（ゲスト）も名前で入れられます
- メンバーを消しても、その人がまだ Discord サーバーにいれば、次に開いたときにまたメンバーになります。入れなくするには、Discord サーバーから外します

## 管理者

管理者になるのは、次の人です。

- グループを作った人
- 管理画面の「管理者」で、管理者にされた人
- そのグループの Discord サーバーで、オーナーか「サーバー管理」「管理者」の権限を持つ人（メンバーの一覧で印が無くても、いつも管理者です）

管理者だけができること:

- 卓を消す・卓をまとめて変える
- メンバーを足す・消す・ほかの人の名前を直す
- 設定を変える（Discord・知らせ・管理者・グループの名前）
- グループを消す

卓を消すほかは、[管理画面](./admin)でします。

卓予定は、みんなが Discord でログインして使います。予定・参加希望・日程調整の回答は、本人だけが入れます。管理者も、ほかの人の代わりには入れません。なので、ゲスト（メンバーに無い人）の予定や回答は入れられません。日程調整の「全員の回答がそろった」は、回答できる人（ログインしたことがあるか、Discord の ID が入っているメンバー）で数えます。

開催日を決める（日程調整で候補日を選ぶ）のは、その卓の GM か管理者です。
