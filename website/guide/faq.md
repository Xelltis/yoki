# よくある質問

## ログインとグループ

### グループに入れない（「このグループには入れません」と出る）

入れるのは、グループの Discord サーバーにいる人だけです。サーバーに入っているか確かめてください。入ったばかりなら、卓予定の入口から開き直します。サーバーを抜けた人は、1 日ほどで入れなくなります。

### 「グループを作る」に自分のサーバーが出てこない

グループを作るには、そのサーバーのオーナーか、「サーバー管理」の権限が要ります。権限をもらったばかりなら、入口の「Discord サーバーの一覧を読み直す」を押します。

### 「あなた」の名前を変えたい

「あなた」は、Discord でログインした本人です。初めて開いたときの Discord の表示名が、メンバーの名前になります。名前は <Ui icon="person_add">メンバーの登録</Ui> タブで、自分で直せます。

### 共用の PC で開いてしまった

ログアウトすると、そのブラウザのログインが消えます。PC では右上のボタン、スマホでは <Ui icon="settings">設定</Ui> タブの「この端末」にあります。

## 画面

### ほかの人が入れた予定が出てこない

右上の「更新」を押してください。時刻の横の点が赤いときは読み込めていないので、通信を確かめてから押し直します。くわしくは [最新の状態にする](./sync)。

### 決まった日を変えたい

カレンダーでその日を押し、内訳の「編集」から開催日を直します。窓の「Discord に知らせる」を付けて保存すると、変更がみんなに流れます。

### はじめの 3 ステップをもう一度見たい

上の「使い方」の隣にある <Ui icon="flag">はじめの 3 ステップ</Ui> を押すと、カレンダーの上にもう一度出ます。スマホでは、上の帯にある旗のボタンです。もう一度押すか、右上の × を押すと閉じます。

### 押しても何も起きない

窓が開いたままのときは、Esc か「閉じる」で閉じてから押します。

### 「管理者だけです」と出る

その操作は管理者だけができます。管理者に頼むか、管理者にしてもらいます。くわしくは [メンバーと管理者](./members)。

## Discord

### 知らせが届かない

設定タブの「最近の送信記録」に、届かなかった理由が出ます。「Webhook URL が違う」と出たら、Discord で Webhook を作り直して貼り直します。くわしくは [Discord に知らせる](./discord)。
