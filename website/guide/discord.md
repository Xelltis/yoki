# Discordに知らせる

知らせは、YokiのBotがDiscordのチャンネルに書き込みます。メンバーにDiscordのIDが入っていれば、その人にメンションが付きます（Discordでログインしたことのある人には、IDが自動で入ります）。

知らせの設定は、[管理画面](./admin)の <Ui>知らせ</Ui> の区分です。変えられるのは管理者だけです。

## はじめにBotを招く

1. 管理画面の <Ui>知らせ</Ui> を開き、「チャンネル」を開く
2. <Ui icon="add" primary>Botをサーバーに招く</Ui> を押す。Discordの画面が開くので、グループのサーバーに招く（そのサーバーで「サーバー管理」の権限が要ります）
3. Yokiに戻って <Ui icon="refresh">読み直す</Ui> を押すと、チャンネルを選べるようになる
4. 「基本のチャンネル」で知らせを送るチャンネルを選んで保存し、「接続テスト」で届くか確かめる

Botには「チャンネルを見る」「メッセージを送信」「埋め込みリンク」の権限が付きます。限られた人だけが見られるチャンネルに送るときは、Discordでそのチャンネルの権限を開き、YokiのBotを許可してください。

## 届く知らせ

| 知らせ | いつ | 送り先 |
|---|---|---|
| 登録・変更・削除 | 卓を保存したとき（「Discordに知らせる」を付けたとき） | 卓に合わせて（募集中の卓は募集のチャンネル） |
| 開催前の知らせ | 開催日のN日前のH時台（設定で決める。シリーズごとにも変えられる） | 開催前の知らせのチャンネル |
| 期間前の催促 | 募集中・調整中のまま、期間の始まる前日（開催前の知らせと同じ時刻台） | 卓に合わせて |
| 締め切りの知らせ | 募集の締め切りの日（開催前の知らせと同じ時刻台）。集まった参加希望の人数をGMに | 卓に合わせて |
| 日程調整の催促・締め切り | 日程調整の回答の締め切りの前日に、まだ答えていない人へ。締め切りの次の日に、GMへ結果を（どちらも開催前の知らせと同じ時刻台） | 卓に合わせて |
| 開始直前の知らせ | 卓の当日、開始のN分前 | 開催前の知らせのチャンネル |
| 日程調整・回答そろい・日程決定 | 日程調整を始めたとき・全員が答えたとき・開催日を決めたとき | 卓に合わせて |
| 参加確認 | 募集中の卓で「興味ありの人に聞く」を押したとき | 募集のチャンネル |
| 行けなくなった | 参加者が「行けなくなった」を押したとき。GMに、本人の一言を添えて | 卓に合わせて |
| 繰り上げ | キャンセル待ちの人が、空きが出て参加希望に繰り上がったとき・GMが参加者に繰り上げたとき。その人に | 卓に合わせて |
| 準備の知らせ | 卓の準備の窓で、GMか管理者が「Discordに知らせる」を押したとき（HOの割り当てと締め切り。秘匿HOは載せない） | 卓に合わせて |
| キャラシの催促 | キャラシの締め切りの前日（開催前の知らせと同じ時刻台）。まだ出していない参加者に | 開催前の知らせのチャンネル |

## 開催前の知らせ

管理画面の「知らせ」の表で「開催日の何日前の何時台」を決めてONにすると、その日時に卓の知らせが届きます。0日前なら当日、1日前なら前日です。

## 期間の前日に催促が届く

募集中・調整中のまま期間の始まる前日になると、GMにメンション付きで届きます。開催前の知らせと同じ時刻台です。募集の締め切りを決めた卓は、締め切りの日にも、集まった参加希望の人数がGMに届きます。日程調整の回答の締め切りを決めた卓には、その前日の催促と、締め切りが過ぎた知らせも届きます（[日程を決める](./decide)）。止めるときは、どれも「知らせ」の表の「期間前の催促」です。

## 開始の少し前に知らせる

「知らせ」の表の「開始直前の知らせ」をONにすると、卓の当日、開始の ◯ 分前にGMと参加者へ届きます。開始時刻を入れた「開催」の卓だけです。5分ごとの見回りで送るので、少し遅れて届きます。

## 卓の案内をいま送る

カレンダーで日を押し、内訳の「Discordに通知」を押してください。登録や変更の窓で「Discordに知らせる」を付けて保存しても流れます。

## 興味ありの人に聞く

募集中の卓で、興味ありの人にメンションして、参加できそうかを尋ねます（一言を添えられます）。

## チャンネルを分ける

- **種類ごとのチャンネル**: 「チャンネル」の「種類ごとのチャンネル」でチャンネルを選ぶと、開催前の知らせと、募集の知らせ（募集の卓の登録や、興味ありの人への参加確認）だけを、そのチャンネルに送れます。「基本のチャンネルと同じ」なら基本のチャンネルへ届きます
- **シリーズごとのチャンネルと日時**: 「シリーズごとの上書き」で、シリーズ専用のチャンネルと、開催前の知らせの日時を決められます。「基本のチャンネルにも送る」を付けると、両方に届きます。決めていないシリーズは、基本のチャンネルへ基本の日時に届きます

## 卓ごとのスレッドにまとめる

「知らせ」の区分の「卓ごとのスレッド」を入れると、卓の最初の知らせのメッセージからスレッドができます。その卓のあとの知らせ（変更・日程調整・回答そろい・準備・催促・開始直前・行けなくなった）の書き先は、そのスレッドです。チャンネルには卓ごとに1通だけが並ぶので、流れにくくなります。何卓かをまとめた開催前の知らせは、チャンネルに書く決まりです。

スレッドを作るには、Botに「公開スレッドの作成」と「スレッドでメッセージを送信」の権限が要ります。<Ui icon="add">スレッドの権限を付けてBotを招き直す</Ui> を押し、もう一度グループのサーバーにBotを招いてください。スレッドを作れないときは送信の記録に理由が出て、知らせはチャンネルに書きます。消したスレッドは、次の知らせで作り直す仕組みです。

## Discordのイベントにも出す

「知らせ」の区分の「Discordのイベント」をONにすると、「開催」の卓（これから60日のうち、20件まで）が、Discordのサーバーのイベントにも出ます。サーバーの「イベント」から卓の予定が見え、「興味あり」も押せます。卓を変えたり中止にしたりしたときは、数分でイベントも直るはずです。始まったイベントは、終わりの時刻に自動で終わります。

イベントを作るには、Botに「イベントを作成」の権限が要ります。<Ui icon="add">イベントの権限を付けてBotを招き直す</Ui> を押し、もう一度グループのサーバーにBotを招いてください。すでにBotがいても、権限を足すために招き直します。

イベントは、チャンネルではなくサーバーにいる人全員に見えます。卓の名前・日時・場所・GMと参加者・メモが出るので、見られて困ることは書かないでください。Discordでイベントを消しても、次に卓を変えたときに作り直します。

## ボタンで答える

運営者が運営の管理画面で「Discordのボタン」を入れたYokiでは、日程調整と募集の知らせにボタンが付きます（[日程調整に答える](./vote#discordのボタンで答える)・[卓に参加する](./join#discordのボタンで付ける)）。押した人は、DiscordのIDでグループのメンバーに結びつき、本人の回答や参加希望として入ります。

## 届かないときは送信の記録

届かなかった理由が分かるのは、管理画面の <Ui>送信の記録</Ui> です。Discordが混んでいて断ったときは、少し待って3回まで送り直します。

「チャンネルの権限」と出たら、Botがそのチャンネルを見られないか、書き込めません。Discordでチャンネルの権限を開き、YokiのBotに「チャンネルを見る」「メッセージを送信」「埋め込みリンク」を許可してください。「チャンネル」と出たら、チャンネルが消されたか、Botがサーバーから外されています。Botを招き直して、チャンネルを選び直してください。「Botの設定」と出たら、そのYokiの運営者の設定（Botのトークン）の問題なので、運営者に知らせてください。
