# Discord に知らせる

知らせは、卓予定の Bot が Discord のチャンネルに書き込みます。メンバーに Discord の ID が入っていれば、その人にメンションが付きます。Discord でログインしたことのある人には、ID が自動で入ります。

知らせの設定は、[管理画面](./admin)の <Ui>知らせ</Ui> にあります。変えられるのは管理者だけです。

## はじめに Bot を招く

1. 管理画面の <Ui>知らせ</Ui> を開き、「チャンネル」を開く
2. <Ui icon="add" primary>Bot をサーバーに招く</Ui> を押す。Discord の画面が開くので、グループのサーバーに招く（そのサーバーで「サーバー管理」の権限が要ります）
3. 卓予定に戻って <Ui icon="refresh">読み直す</Ui> を押すと、チャンネルを選べるようになる
4. 「基本のチャンネル」で知らせを送るチャンネルを選んで保存し、「接続テスト」で届くか確かめる

Bot には「チャンネルを見る」「メッセージを送信」「埋め込みリンク」の権限が付きます。限られた人だけが見られるチャンネルに送るときは、Discord でそのチャンネルの権限を開き、卓予定の Bot を許可してください。

## 届く知らせ

| 知らせ | いつ | 送り先 |
|---|---|---|
| 登録・変更・削除 | 卓を保存したとき（「Discord に知らせる」を付けたとき） | 卓に合わせて（募集中の卓は募集のチャンネル） |
| 開催前の知らせ | 開催日の N 日前の H 時台（設定で決める。シリーズごとにも変えられる） | 開催前の知らせのチャンネル |
| 期間前の催促 | 募集中・調整中のまま、期間の始まる前日（開催前の知らせと同じ時刻台） | 卓に合わせて |
| 開始直前の知らせ | 卓の当日、開始の N 分前 | 開催前の知らせのチャンネル |
| 日程調整・回答そろい・日程決定 | 日程調整を始めたとき・全員が答えたとき・開催日を決めたとき | 卓に合わせて |
| 参加確認 | 募集中の卓で「興味ありの人に聞く」を押したとき | 募集のチャンネル |

## 開催前の知らせ

管理画面の「知らせ」の表で「開催日の何日前の何時台」を決めて ON にすると、その日時に卓の知らせが届きます。0 日前なら当日、1 日前なら前日です。

## 期間の前日に催促が届く

募集中・調整中のまま期間の始まる前日になると、GM にメンション付きで届きます。開催前の知らせと同じ時刻台です。「知らせ」の表の「期間前の催促」で止められます。

## 開始の少し前に知らせる

「知らせ」の表の「開始直前の知らせ」を ON にすると、卓の当日、開始の ◯ 分前に GM と参加者へ届きます。開始時刻を入れた「開催」の卓だけです。5 分ごとの見回りで送るので、少し遅れて届きます。

## 卓の案内をいま送る

カレンダーで日を押し、内訳の「Discord に通知」を押します。登録や変更の窓で「Discord に知らせる」を付けて保存しても流れます。

## 興味ありの人に聞く

募集中の卓で、興味ありの人にメンションして、参加できそうかを尋ねます。一言を添えられます。

## チャンネルを分ける

- **種類ごとのチャンネル**: 「チャンネル」の「種類ごとのチャンネル」でチャンネルを選ぶと、開催前の知らせと、募集の知らせ（募集の卓の登録や、興味ありの人への参加確認）だけを、そのチャンネルに送れます。「基本のチャンネルと同じ」なら基本のチャンネルへ届きます
- **シリーズごとのチャンネルと日時**: 「シリーズごとの上書き」で、シリーズ専用のチャンネルと、開催前の知らせの日時を決められます。「基本のチャンネルにも送る」を付けると、両方に届きます。決めていないシリーズは、基本のチャンネルへ基本の日時に届きます

## 届かないときは送信の記録

管理画面の <Ui>送信の記録</Ui> に、届かなかった理由が出ます。Discord が混んでいて断ったときは、少し待って 3 回まで送り直します。

- **チャンネルの権限**: Bot がそのチャンネルを見られないか、書き込めません。Discord でチャンネルの権限を開き、卓予定の Bot に「チャンネルを見る」「メッセージを送信」「埋め込みリンク」を許可します
- **チャンネル**: チャンネルが消されたか、Bot がサーバーから外されています。Bot を招き直して、チャンネルを選び直します
- **Bot の設定**: 卓予定を公開している運営者の設定の問題です。運営者に知らせてください
