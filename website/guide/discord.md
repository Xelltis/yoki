# Discord に知らせる

知らせは、Discord の Webhook でチャンネルに投稿します（Bot は使いません）。メンバーに Discord の ID が入っていれば、その人にメンションが付きます。Discord でログインしたことのある人には、ID が自動で入ります。

知らせの設定は <Ui icon="settings">設定</Ui> タブにあり、変えられるのは管理者だけです。

## 届く知らせ

| 知らせ | いつ | 送り先 |
|---|---|---|
| 登録・変更・削除 | 卓を保存したとき（「Discord に知らせる」を付けたとき） | 卓に合わせて（募集中の卓は募集のチャンネル） |
| 開催前の知らせ | 開催日の N 日前の H 時台（設定で決める。シリーズごとにも変えられる） | 開催前の知らせのチャンネル |
| 期間前の催促 | 募集中・調整中のまま、期間の始まる前日（開催前の知らせと同じ時刻台） | 卓に合わせて |
| 開始直前の知らせ | 卓の当日、開始の N 分前 | 開催前の知らせのチャンネル |
| 日程調整・回答そろい・日程決定 | 日程調整を始めたとき・全員が答えたとき・開催日を決めたとき | 卓に合わせて |
| 参加確認 | 募集中の卓で「興味ありの人に聞く」を押したとき | 募集のチャンネル |

## 開催前の知らせ

設定タブで「開催日の何日前の何時台」を決めて有効にすると、その日時に卓の知らせが届きます。0 日前なら当日、1 日前なら前日です。

## 期間の前日に催促が届く

募集中・調整中のまま期間の始まる前日になると、GM にメンション付きで届きます。開催前の知らせと同じ時刻台です。設定タブの「そのほかの知らせ」で止められます。

## 開始の少し前に知らせる

設定タブの「そのほかの知らせ」で ON にすると、卓の当日、開始の ◯ 分前に GM と参加者へ届きます。開始時刻を入れた「開催」の卓だけです。5 分ごとの見回りで送るので、少し遅れて届きます。

## 卓の案内をいま送る

カレンダーで日を押し、内訳の「Discord に通知」を押します。登録や変更の窓で「Discord に知らせる」を付けて保存しても流れます。

## 興味ありの人に聞く

募集中の卓で、興味ありの人にメンションして、参加できそうかを尋ねます。一言を添えられます。

## チャンネルを分ける

- **種類ごとのチャンネル**: 設定タブの「種類ごとのチャンネル」に URL を貼ると、開催前の知らせと、募集の知らせ（募集の卓の登録や、興味ありの人への参加確認）だけを、そのチャンネルに送れます。空なら基本のチャンネルへ届きます
- **シリーズごとのチャンネルと日時**: 設定タブの「シリーズごとの通知」で、シリーズ専用の Webhook URL と、開催前の知らせの日時を決められます。「基本のチャンネルにも送る」を付けると、両方に届きます。決めていないシリーズは、基本のチャンネルへ基本の日時に届きます

## 届かないときは送信の記録

設定タブの「最近の送信記録」に、届かなかった理由が出ます。Discord が混んでいて断ったときは、少し待って 3 回まで送り直します。「Webhook URL が違う」と出たら、Discord で Webhook を作り直して貼り直します。

::: warning Webhook の URL は仲間の外に出さない
Webhook の URL を知っている人は、誰でもそのチャンネルに投稿できます。卓予定の画面にも、伏せた形でしか出しません。
:::
