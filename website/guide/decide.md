# 日程を決める

調整中の卓のカードで <Ui icon="how_to_vote" primary>日程を調整する</Ui> を押し、候補日を選びます。卓を「調整中」で登録したときは、保存するとこの窓がそのまま開きます。

開催日を決めるのは、その卓の GM か管理者です。

## 候補日の横に、みんなの予定が出る

各日の右に、GM と参加者の印（全員空き・△・×・卓あり）が並びます。「全員空きの日だけ」で絞り込めます。

## 「この候補日で聞く」で知らせる

「Discord で知らせる」を付けたまま送ると、GM と参加者を呼んで、候補日と答え方を流します。出した人の ◯ は、最初から付いています。

みんなの答え方は [日程調整に答える](./vote) にあります。

## 全員がそろったら、開催日を選ぶ

全員の回答がそろうと、GM に Discord で知らせが届きます。ゲストと、Discord の ID の無いメンバーは回答できないので、数えません。候補日の「この日に決める」を押すと、卓の状態は「開催」になり、Discord に「日程が決まりました」と流れます。

## 選び直す・やめる

「候補日を選び直す」では、外した日の回答だけが消えます。「調整をやめる」で候補日と回答を消しても、卓は調整中のまま残ります。
