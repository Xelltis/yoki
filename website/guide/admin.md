# 管理画面

メンバーの登録や Discord の知らせなど、管理者が使うものは、グループの**管理画面**にまとまっています。開けるのは、そのグループの管理者だけです（誰が管理者かは [メンバーと管理者](./members)）。

## 開き方

グループの画面の右上にある <Ui icon="shield">管理</Ui> を押します（管理者にだけ出ます。狭い画面ではアイコンだけです）。右上の自分の名前から開く <Ui icon="settings">設定</Ui> の「グループの管理画面」からも開けます。管理画面の URL は、グループの URL のあとに `admin/` を付けたもの（`…/g/xxxxxxxxxx/admin/`）です。

ふだんの画面に戻るときは、上の帯の <Ui icon="arrow_back">予定の画面へ</Ui> を押します（スマホでは矢印だけが出ます）。

## 区分

左の区分を押して切り替えます。スマホでは上に横に並ぶので、横にずらして選びます。

| 区分 | すること |
|---|---|
| メンバー | メンバーを足す・消す、名前・備考・Discord の ID を直す |
| 卓をまとめて変える | 卓の一覧から選び、参加者の出入り・開催日のずらし・状態やシリーズの変更・削除をまとめてする |
| 知らせ | 卓予定の Bot を Discord サーバーに招く、知らせのチャンネル、開催前の知らせの日時、知らせの ON/OFF、シリーズごとの上書き（[Discord に知らせる](./discord)） |
| このグループ | グループの名前、過ぎた卓の後始末、表示 |
| 管理者 | 管理者を足す・外す |
| 送信の記録 | Discord に送った知らせと、届かなかった理由（新しい順 10 件） |
| グループを消す | グループをまるごと消す（下） |

## グループを消す

区分の <Ui>グループを消す</Ui> の欄に、確かめのためにグループの名前をそのまま入れると、ボタンが押せるようになります。

- 卓・メンバーの予定・メモ・日程調整の回答・送信の記録が、すべて消えます。**元に戻せません**
- ほかの人が開いていた画面には、「グループが見つかりません」と出ます
- Discord のチャンネルに貼った知らせは消えません
