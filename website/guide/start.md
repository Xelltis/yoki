# 始め方

卓予定は、TRPGの卓の予定をDiscordサーバーの仲間と管理するWebアプリです。仲間の都合から**全員が空いている日**を見つけて、卓の日程を決めるまでを1か所で済ませます。

グループはDiscordサーバーごとに作ります。グループに入れるのは、そのサーバーにいる人だけです。

## グループを作る

グループを作れるのは、Discordサーバーのオーナーか、「サーバー管理」の権限を持つ人です。卓予定を公開している運営者が新しい登録の受付を止めているあいだは、作れません。

1. 卓予定の入口を開き、「Discordでログイン」を押します。初めてのときは、Discordが「卓予定にアカウントの情報を渡すか」を聞くので、許可します。渡すのは、名前と、入っているサーバーの一覧だけです
2. 「グループを作る」でDiscordサーバーを選び、「作る」を押します
3. できたグループのURL（`…/g/xxxxxxxxxx/`）を、そのサーバーのチャンネルに貼ります

グループを作った人は、そのグループの管理者になります。1つのDiscordサーバーに、グループをいくつ作ってもかまいません（卓のサークルが複数あるときなど）。

## Googleでもログインする

運営者がGoogleの設定をしていれば、入口に「Googleでログイン」が出ます。卓予定の利用者はDiscordのアカウントで決まり、Googleのアカウントは、それに結びつけたもう1つの入り口です。Discordにログインしていないブラウザやスマホで開くときに便利です。

初めてのGoogleアカウントで「Googleでログイン」を押すと、続けて「Discordでログイン」を求められ、Discordでログインすると結びついて、次からはGoogleだけで入れます。ログインしたあとなら、右上の自分の名前から開く <Ui icon="settings">設定</Ui> の「ログインの方法」で結びつけたり、外したりできます。Googleから受け取るのは、アカウントのIDとメールアドレスだけです。入れるグループは、Discordでログインしたときと同じです。Discordサーバーにいるかは、そのサーバーに卓予定のBotがいればBotで確かめ、いなければ1日に1回Discordに聞き直します。

## はじめの3ステップ

グループができたら、次の順で準備してください。グループの画面のカレンダーの上にも、<Ui icon="flag">はじめの3ステップ</Ui> として同じ手順が出て、仲間が入って卓ができると自動で消えます。

### 1. 仲間を招く

<Ui icon="link">URLを写す</Ui> を押して、グループのURLをDiscordサーバーのチャンネルに貼ります。開いてDiscordでログインした人は、自動でメンバーになります。DiscordのIDも自動で入るので、知らせでその人にメンションが付きます。

まだ開いていない人は、管理者が[管理画面](./admin)の <Ui>メンバー</Ui> で、名前とDiscordのIDを先に入れておけます。メンバーの名前は、そのまま予定表の列と参加者の候補です。くわしくは [メンバーと管理者](./members)。

### 2. 卓を登録する

タブの <Ui icon="calendar_month">カレンダー</Ui> で日を選んで <Ui icon="add" primary>卓を登録</Ui> を押します。日が決まっていなければ、「募集を始める」か「日程調整を始める」から登録します。くわしくは [卓を登録する](./register)。

### 3. Discordに知らせる（任意）

卓の案内や開催前の知らせをDiscordに送るなら、管理者が設定します。知らせが要らないなら、飛ばしてかまいません。

右上の <Ui icon="shield">管理</Ui> から管理画面を開き、<Ui>知らせ</Ui> の「チャンネル」で <Ui icon="add" primary>Botをサーバーに招く</Ui> を押して、卓予定のBotをグループのDiscordサーバーに招きます。戻って「読み直す」を押し、「基本のチャンネル」で知らせを送るチャンネルを選んで保存し、「接続テスト」で届くか確かめます。チャンネルをまだ決めていないあいだは、「チャンネル」が表より上に開いた状態です。

開催前の知らせを自動で送るなら、同じ区分の表で「開催前の知らせ」をONにします。くわしくは [Discordに知らせる](./discord)。
