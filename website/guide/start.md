# 始め方

卓予定は、TRPG の卓の予定を Discord サーバーの仲間と管理する Web アプリです。仲間の都合から**全員が空いている日**を見つけて、卓の日程を決めるまでを 1 か所で済ませます。

グループは Discord サーバーごとに作ります。グループに入れるのは、そのサーバーにいる人だけです。

## グループを作る

グループを作れるのは、Discord サーバーのオーナーか、「サーバー管理」の権限を持つ人です。卓予定を公開している運営者が新しい登録の受付を止めているあいだは、作れません。

1. 卓予定の入口を開き、「Discord でログイン」を押します。初めてのときは、Discord が「卓予定にアカウントの情報を渡すか」を聞くので、許可します。渡すのは、名前と、入っているサーバーの一覧だけです
2. 「グループを作る」で Discord サーバーを選び、「作る」を押します
3. できたグループの URL（`…/g/xxxxxxxxxx/`）を、そのサーバーのチャンネルに貼ります

グループを作った人は、そのグループの管理者になります。1 つの Discord サーバーに、グループをいくつ作ってもかまいません（卓のサークルが複数あるときなど）。

## はじめの 3 ステップ

グループができたら、管理者が次の順で準備します。グループの画面の <Ui icon="flag">はじめの 3 ステップ</Ui> にも、同じ手順が出ます。

メンバーの登録と Discord の設定は、グループの[管理画面](./admin)でします。PC ではタブの並びの <Ui icon="shield">管理</Ui>、スマホでは <Ui icon="settings">設定</Ui> タブの「グループの管理画面」から開きます。はじめの 3 ステップのボタンからも、管理画面の該当の区分へ移れます。

### 1. メンバーを登録する

グループの URL を開いて Discord でログインした人は、自動でメンバーになります。Discord の ID も自動で入るので、知らせでその人にメンションが付きます。

まだ開いていない人や、Discord を使わない人は、管理画面の <Ui>メンバー</Ui> で名前を入れます。メンバーの名前が、予定表の列と参加者の候補になります。くわしくは [メンバーと管理者](./members)。

### 2. Discord を登録する

管理画面の <Ui>知らせ</Ui> の「チャンネル」で、<Ui icon="add" primary>Bot をサーバーに招く</Ui> を押して、卓予定の Bot をグループの Discord サーバーに招きます。戻って「読み直す」を押し、「基本のチャンネル」で知らせを送るチャンネルを選んで保存し、「接続テスト」で届くか確かめます。

開催前の知らせを自動で送るなら、同じ区分の表で「開催前の知らせ」を ON にします。Discord を使わないなら、飛ばしてかまいません。くわしくは [Discord に知らせる](./discord)。

### 3. 予定を登録する

<Ui icon="calendar_month">カレンダー</Ui> で日を選んで <Ui icon="add" primary>卓を登録</Ui> を押します。日が決まっていなければ、状態を「募集」か「調整中」にして登録します。くわしくは [卓を登録する](./register)。
