# 日程調整に答える

GM が候補日を出すと、Discord に知らせが届きます。候補日ごとに ◯ か × を押します。全員が答えると GM に知らせが届き、GM が開催日を選びます。

<VoteDemo />

## 「募集・調整」タブで答える

上の <Ui icon="campaign">募集・調整</Ui> タブの、日程調整中のカードに候補日が並びます。同じ印をもう一度押すと、取り消せます。

## どの日でもよければ 1 回で済む

候補日の見出しの右にある <Ui icon="check">どの日でもいい</Ui> を押すと、これからの候補日すべてに ◯ が付きます。もう一度押すと、自分の回答だけを取り消せます。

## 開催日は GM が選ぶ

全員の回答がそろうと、GM に Discord で知らせが届きます。ゲストと、Discord の ID の無いメンバーは回答できないので、数えません。GM が候補日の「この日に決める」を押すと、卓の状態は「開催」になり、Discord に「日程が決まりました」と流れます。

## 自分の番は「グループの予定」の欄に出る

カレンダーの右（スマホでは下）の「グループの予定」の欄に、「あなたの回答を待っています」と色付きで出ます。押すと、その卓のカードへ移ります。

上の <Ui icon="campaign">募集・調整</Ui> タブにも、あなたの番の数（まだ答えていない日程調整と、GM として開催日を選ぶ日程調整）が出ます。答えると消えます。
