# 運営の管理画面

運営の管理画面は、Yokiを設置した運営者が使う画面です。開けるのは、Workerのsecretの `OPERATOR_IDS` にDiscordユーザーIDを書いた人だけです（[設置する](./#_2-ボタンを押して設置する)）。運営者を足すときや替えるときは、この値を直してください。各グループの管理者が使う「グループの管理画面」とは別の画面になります（[管理画面](../guide/admin)）。

## 開き方

運営者としてログインすると、入口の画面と、グループの画面のグループの切り替えに「運営の管理画面」のリンクが出ます。アドレスは、公開したアドレスのあとに `/admin/` を付けたものです。

## 区分

| 区分 | すること |
|---|---|
| 様子 | グループ・利用者・有効なログイン・動いている卓の数、知らせの見回りが動いているか、Botのトークンが使えるか、Discordへの送信の失敗を見る。新規登録の受付・Discordのボタン・運営者への知らせを切り替える |
| グループ | グループの一覧と中身を見る。管理者やDiscordサーバーを付け替える、グループを消す |
| 利用者 | ログインを切る、締め出す・戻す、消す |
| 規約 | 利用規約とプライバシーポリシーの、運営者の名前・問い合わせ先・本文を直す |
| 更新 | 動いているバージョンと、新しいバージョン・変わったことを見て、新しいバージョンに上げる（[新しいバージョンに上げる](./update)） |

運営者でも、グループの中身（卓・予定）は見られません。運営者がした操作は、CloudflareのWorkersのログ（Observability）に1行ずつ残ります。`"audit"` で探してください。

## 様子

数の「有効なログイン」は、ブラウザ・端末ごとの数です。ログアウトせずに使わなくなったものも、30日の期限が切れるまでは数に入ります。

知らせの見回りは、Cloudflareが5分ごとに動かします。止まっていれば、ここに注意が出るはずです。Discordへの送信の失敗には、グループと理由が並びます。

YokiのBotのトークンが使えなくなると（Developer Portalでトークンを作り直したときなど）、いちばん上に注意が出ます。そのあいだは、Discordへの知らせが届きません。DiscordのDeveloper PortalでBotのトークンを作り直し、Workerのsecretの `DISCORD_BOT_TOKEN` を入れ直してください（[Discordの準備](./discord)）。見回りが1時間に1回確かめるので、直ってから注意が消えるまで、少しかかります。

## 新規登録の受付

受付の切り替えは、「様子」の中です。止めると、新しいグループの作成と、初めての人のログインを断ります。もう使っている人と今あるグループは、そのまま使えます。

使う人を、知り合いのサーバーだけに絞りたいときに止めてください。運営者は、止めていてもログインでき、グループも作れます。初めは受け付けている状態です。

## Discordのボタン

「様子」の中の「Discordのボタン」を入れると、日程調整と募集の知らせにボタンが付きます。グループのメンバーは、Discordのまま「予定表から答える」「どの日でもいい」「行ける日を選ぶ」「参加希望」「興味あり」を押せます。返事が見えるのは、押した本人だけです。

入れるときは、YokiがBotのトークンを使って、DiscordアプリのPublic Keyを読み、アプリの「Interactions Endpoint URL」に `https://<公開のアドレス>/api/discord/interactions` を入れます。Discordがそのアドレスに届くかを確かめるので、公開のアドレスで開いた運営の管理画面から入れてください（手元の開発サーバーからは入れられません）。止めると、それからの知らせにはボタンを付けません。

## 運営者への知らせ

YokiのBotが、運営者（`OPERATOR_IDS` の人）にDiscordのDMを送ります。送るのは、次のときです。

| とき | 中身 |
|---|---|
| 新しいバージョンが出た | バージョン・表の変更があるか・変わったことのリンク・「更新」の区分へのリンク。毎日10時台に1回見て、同じバージョンは2度送りません |
| 知らせの見回りが3回続けて失敗した | 失敗の理由。続けて失敗しているあいだは1回だけです |
| Botのトークンが、また使えるようになった | 使えなかった時間。そのあいだの知らせは届いていないので、各グループの「送信の記録」で確かめられます |

DMが届くのは、Botと同じDiscordサーバーにいて、サーバーのメンバーからのDMを許している人だけです。「様子」の「運営者への知らせ」の「自分に試しに送る」で、届くかを確かめてください。届かなければ、その理由が出ます。

知らせは、初めは送る状態です。止めるときは「知らせを止める」を押してください。

## グループ

グループを開くと、Discordサーバー・メンバーの数・卓の数・最後に使われた日が出ます。管理者がいなくなったグループの管理者も、ここで付け替えられます。

グループを消すときは、確かめのために、グループの名前を打ち込んでください。中身もすべて消え、元に戻せません。

## 利用者

| 操作 | 何が起きるか |
|---|---|
| ログインを切る | その人のログインを、どの端末のものもすべて消す。Discordでログインし直せば、また入れる |
| 締め出す | Discordでログインできなくなり、残っていたログインも効かなくなる。理由を控えられる |
| 戻す | 締め出しをやめる |
| 消す | その人の情報を消す（下） |

締め出しはDiscordのアカウントで止めるので、別のアカウントを作られると止められません。運営者は締め出せません。

消すのは、本人から消してほしいと頼まれたときです（プライバシーポリシーの「消し方」）。その人のログイン・Discordの名前・入っているサーバーの控えと、どのグループのメンバーの行も消えます。予定とメモは消え、卓と回答には名前だけが残る形です。Googleカレンダーと連携していれば、書き込んだ予定を消し、Googleの許可を取り消してから消します。

消しても、その人がDiscordサーバーにいれば、次に開いたときにまた入れます。運営者と、締め出している人は消せません（締め出しの印も消えてしまうため）。

## 規約

利用規約（`/terms`）とプライバシーポリシー（`/privacy`）の、運営者の名前・問い合わせ先・本文を直せます。直していなければ、出るのは既定の文です。本文を空にして保存すると、既定の文に戻ります。

2つのページは、ログインしていない人でも読めるページです。入口の画面と、グループの画面の設定からリンクしています。
